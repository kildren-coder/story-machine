# 0009. 原话由程序抄定：模型只给位置，字从逐字稿来

**Date:** 2026-10-20（决定形成于 2026-10-14 至 10-17）
**Status:** Accepted

## Context

v3 的做法：L2 把原话逐字抄进产物，L3 闸门 1 查它是不是逐字稿某一段的连续子串，对不上整条删。「段」是一个 30 秒语音块。核实第 2、3 步时查出几件事：

- **模型看的单位和闸门查的单位不一致。** L2 看到的「行」是 30 秒窗里同一人的几段用空格拼起来的，模型连空格都照抄；闸门却按「段」查。EP01 唯一被删的一条逐字都对，只因跨了一个 30 秒块界。两集 233 条原话删 2 条：EP02 那条是真抓到（模型少抄一个字），EP01 这条是误删。
- **漏洞。** `claims[].quote`（说法的依据原话）闸门根本不查；`ctx`（原话所在整块的全文）存着但没有任何一层读。
- **#83 补不上。** 近似命中归一（#83，已合入）能救 EP02 那条，但明说不管跨段；它的前提「`ctx` 与 `quotes` 后面没有任何一层读」在述线制下不成立，深加工要读原话。
- **时刻只到块。** 块级时刻比真实开口早：EP01 一条原话标的时刻早 23 秒，一个段落早 9 秒。
- **闸门 3（限定词）没做过，做了也不值。** 按 SPEC 的定义实测：EP01 62 条说法触发 0 条；EP02 147 条触发 6 条、报警 3 条，其中真丢 1 条、字还在只是没标 1 条、误报 1 条；它不查说法句本身，报警落在 `gates.json` 里没人看，闸门又不许改字。

转写引擎换成 FireRed 以后（ADR 0006），每个字有时刻，另存一份带标点、去标点后逐字相同的版本。

## Decision

1. **原话由程序抄定（方案 C）。** 模型只给**起始行号加它要引的那几个字**，不再抄全句、不写时刻。代码在那一行起的连续文本里找（去空白、去标点再比），找到了用逐字稿的字替换模型写的，首字时刻查 `words.json`；差一两个字的按 #83 的办法落成逐字稿原字；找不到才删，并在 `gates.json` 记全文。`quotes`、`claims[].quote`、`channels[].quote` 一并走这条路；述段的起点也由模型给起始几个字、代码定位到字。
2. **L2 的规矩随之改。** 「不许跨行拼接」改成「可跨行，但必须连着说」；`ctx` 改成按需取原话所在的句子，不再存 30 秒整段。
3. **新集 L2 输入按句分行（丙）。** FireRed 转的集，L2 输入每句一行、带标点、每句自带时刻；L1 仍用 30 秒块行（切章用不着句级精度，按句会让行数翻几倍）。闸门 1 两边去标点再比，在整章连续文本上找，不再按段。
4. **首字时刻查词表（乙）。** 对上原话后到 `words.json` 查首字时刻，所有集都做，纯代码、不花额度。
5. **闸门 3 不做。** `<hedge>` 标记照留，只作显示（整理稿里限定词显示成下划线），没有代码再读它；说法与原话语气是否一致交给深加工：读说法时原话就附在后面，prompt 加一句「说法与原话语气不一致时以原话为准」。
6. **边界。** 章末端点归下一章（述段与章节都是 `[start, end)`）；越界的段只记不删。`gates.json` 补 `provenance` 与 `passed`。

## Rationale

**字必须来自逐字稿，不能来自模型的手。** 原话是全链路的证据锚点（红线 2），下游核实、读者点时刻听原声，都靠它。模型抄字是错误的来源，闸门再严也只能删不能救；让代码从逐字稿里抄，字就不可能错，模型只需要做它擅长的事：指出哪一句值得引。

**为什么保留模型的定位职责。** 哪几句是「原话锚点」是判断，代码做不了；行号加前几个字是最便宜的定位方式，也和 ADR 0005「模型用行号指位置」一脉相承。

**为什么跨段不再是问题。** 比对的单位改成整章连续文本，30 秒块界就只是时刻的来源，不再是找字的边界；EP01 那条误删不靠按句重切也能救回。

**为什么按句分行只给 L2。** 句级输入让段落和原话的时刻都准到句，又是 L2 看得见的最自然单位；L1 用不着，给了只会把输入翻几倍。

**为什么闸门 3 不做。** 用户关心的是说法真不真，不是那几个限定词；量出来的收益是两集 1 条真丢，代价是一条没人看的报警和一个不能改字的闸门。把原话附在说法后面交给深加工，连说法句自己丢限定词的情况也管住了，还不另起一层。

**为什么 #83 并进来而不是留着。** 近似命中归一解决的是「差一两个字」，C 顺手就能做；留它单独一层，它的前提（没人读原话）又已经不对了。

## Consequences

- L2 prompt 改写：原话与说法依据改给行号加前几个字；跨行规则；`ctx` 不再存整块。`SPEC.md` §4 L2、L3 随 v4 改；L3 第 3 条（闸门 3）删掉。
- 闸门 1 的实现从「段内子串」改成「章内连续文本、去标点比对、查词表定时刻」。
- 已转的 EP01、EP02 是 whisper 正本，没有带标点版，丙只对 FireRed 转的新集生效；乙对所有集生效。
- `_pairs/` 里存着 L2 的原始回复，改好闸门后重放 L2 再跑 L3，零额度找回被误删的那条。
- #54、#72（闸门 3 相关）已关；#83 的近似命中成为 C 的一部分。
- 原话的时刻从块级变成字级，跳播插件（ADR 0001）不用改，只是更准。
