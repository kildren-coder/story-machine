# 0016. 记录存储：JSONL 起步，读写只经记录模块，碰信号换 SQLite

**Date:** 2026-10-23（决定形成于 2026-10-22）
**Status:** Accepted

## Context

0011 定了记录只追加、视图派生，没定记录落在什么存储里。第 9 步核实（L7″ 写回）把记录的落盘定成 `_digest/` 下几份只追加的 JSONL（哪几份、放哪归 SPEC），用户随即问：这些 JSON 以后能不能换成数据库类的存储，还是没必要；系统现在大多建在 Obsidian 上，最终要独立成一套信息处理终端，到那个阶段是否有必要用数据库。

要定的是三件：现在用什么、怎么保证以后换得掉、什么时候换成什么。

## Decision

1. **现在用 JSONL，一行一条记录，只追加。** 记录只追加（0011）落到文件上的最简形状就是追加一行，不读不改。
2. **记录的读写收进一个记录模块。** 追加、扫描、按 id 取，几个函数；所有层只经它碰记录文件，页面渲染、面板、收勾都不直接开文件。换后端只改这一个模块。
3. **记录自带换得掉的条件。** 每条记录带稳定 id、运行 id、schema 版本，该类记录自己的版本（切法版本、轮次）照带；记录里不存派生字段，能从记录重算的（当前视图、问题头的摘要、索引）都标明可重算、丢了重建。
4. **换的信号有三个，碰到一个就换：** ① 重画要扫全部记录而变慢（改判传播、说法匹配候选、说话人三项都是全扫）；② 多进程同写一份记录文件、靠锁文件开始出事（并发大于 1 时，0014 第 6 条）；③ 要做记录之间的即席查询与分析（传播路径、首发者、说话人表现随时间、#92 的贝叶斯更新）。
5. **换成什么：SQLite（WAL 模式）当工作库。** 单文件、零运维、Python 自带，并发读加单写够一个人用的终端用很多年；FTS5 做全文，向量可用 sqlite-vec 一类扩展。换了以后 SQLite 是正本，JSONL 改成每次运行的导出（git 友好的备份、能重建库）；「记录只追加」在表里就是只 INSERT 不 UPDATE，形状不变。Postgres 只在服务化、多用户、多机写入时才值得。
6. **向量索引另算。** 述线 / 述段 / 命题的向量本来就不进记录文件（0008 第 2、5 条：索引是派生物、放 5070、丢了重建），工具由检索调研 #95 定；和这里的记录存储是两件事。
7. **Obsidian 的位置不变。** 现在它是人的界面加文件的宿主；独立成终端后页面层换成自己的 UI 或照旧生成 Markdown，记录层不动。

## Rationale

**为什么现在不上数据库。** 规模撑不起数据库的成本：估一年每次运行约 200 条说法、深加工每题几十条命题，一年约 7 万说法行、3 万命题、15 万来源记录，几十 MB，Python 整份读完几秒，每次重画都读得起。人看的本来就是 Markdown 视图，Dataview 查不了 JSONL 也查不了数据库，存储换不换对人读的页面没影响。JSONL 还能 diff、能 grep、能进 git，调试阶段这三样比查询语言值钱。

**为什么现在就要留换的路。** 换存储的代价不在导数据（JSONL 一行一个对象，导进 SQLite 是几十行脚本、字段即列），在散落各处的直接开文件。记录模块把这个代价收成一个文件；派生字段不存，是为了换后端时不用迁派生物、也不会把过期的派生物当记录迁走。

**为什么是信号而不是日期。** 三个信号各对应数据库真正解决的一件事：索引解决全扫、事务解决同写、查询语言解决即席分析。没碰到信号就换，是为想象中的问题付运维成本；碰到了不换，是拿锁文件和全扫硬扛。

**为什么是 SQLite 不是 Postgres。** 终端是一个人用的桌面软件，Postgres 的多用户、网络、运维全是负担；SQLite 在单写者场景下的并发读完全够，且和 JSONL 一样是一个文件、随 vault 走。

## Consequences

- 第 9 步骨架票的验收加三项：记录只经记录模块读写；每条记录带 id、运行 id、schema 版本；附一个 JSONL 导 SQLite 的脚本并跑通一次，证明换得掉。
- 信号 ① 从 `runs.jsonl` 看：每次运行记重画耗时与记录总数（0015 第 6 条已让它记入口页行数，同一处）。
- 信号 ② 的「出事」指丢行或并发时重画出错，不是重试一次；锁的做法归 0014 第 6 条。
- 碰到信号时另写 ADR 记换库，本 ADR 转 Superseded；0011 不动。
- `SPEC.md` v4 §5 加一句「记录存储可换、读写只经记录模块」；文件布局（哪几份 JSONL、放哪、字段）归 §5 / §6，不进本 ADR。
