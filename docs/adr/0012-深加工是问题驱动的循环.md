# 0012. 深加工是问题驱动的循环：列假设、核实、推理、反方

**Date:** 2026-10-21（决定形成于 2026-10-19 至 10-21）
**Status:** Accepted

## Context

原型（2026-10-09）的深加工是「四问」：一条述线一次调用，把述线说明、核查的 32 条判定、11 个述段的整理稿正文与原话一起喂给 opus（联网），让它写六段散文——讲了什么（现状与说法怎么变）、重大事实偏差、支持与不支持的证据、历史先例与当时 vs 现在、有见地的分析、信源——外加一个述线级的整体徽标。DSA 那条跑通了：1.36 美元、440 秒、27 轮、峰值约 9.3 万 token，输入已 6.5 万而述线只挂了两集。2026-10-21 按核实清单第 8 步，拿默认问题「主播的论点站不站得住」把产物重摆一遍，形状有六处不对：

1. **判的对象没定义。** prompt 要模型判「主线有没有重大偏差」，主线是什么没人写。按问题重摆，这条述线至少有五条可检验的论点（激进化向马列转型、选上被同化、马姆达尼履历浅运动撑不久、未夺权先分裂、民主党 DSA 化），两位说话人各持其一且相反，外部还有两条对立看法（党中之党根基浅、胜利集中深蓝区）。一个 warn 既说不出谁对、也说不出哪条站不住。
2. **「支持 / 不支持」混了三件事。** 22 条里真正对论点打向的 14 条；5 条只是把核查判定换个说法再写一遍，而「主播事实错」不等于「证据反论点」（军费那条事实查不到，方向上反而撑激进化）；2 条离题；1 条「他没提的关键变量」是好东西但没地方放。
3. **先例的事实没核。** 社会党 1912 年的党员数、SDS 的会员数、茶党的两次初选，数字来自模型自带的知识，来源表里四条链接哪条撑哪个数没对上。
4. **抓到的好东西没落字段。** 「说法怎么变」一段抓到两处真矛盾（同一主播两集对「白左」的说法相反；两位说话人对运动前景的判断相反），都写在散文里，台账和证据表都看不见。「有见地的分析」五条里两条其实是对立假设的持有者，一条是价值判断，一条是高诊断力的证据，一条是先例分析，五样东西装在一个「他人观点」的筐里。
5. **「现状」三百字混了三样**：世界进展到哪、他最近怎么说、核查站不站得住。
6. **调用形状**与核查层一样的三件：搜索记成 0（实际 haiku 子代理 16 次）、日期写死在 prompt、输入随整理稿正文涨，大述线装不下。

更根本的是六问缺脊柱。它列的材料都对——完整记录、事实层、两面证据、先例这个外部视角、他人观点、出处——但没有问题、没有判断、没有「什么能改变判断」，六段散文把综合全留给每天只有几分钟的读者。

这期间定下的方向：10-19 定深加工从页面打勾起、面板排队；10-20 用户定深加工按五道工序（正字 / 核实 / 推理 / 串联 / 读意）加「问题的账」走，证据与判断分开存，记录只追加（ADR 0011），改判按依赖传播（0013）；10-21 三轮定下本 ADR 的形状：第一轮四次调用的分工与各自输入输出，第二轮用户定五条（列假设在核实之前、矩阵取代两列、推理不联网、推理不吃正文、反方默认开），第三轮用户定可能性五档、字段表、页面按三个读的时刻排。

## Decision

1. **深加工的单位是问题，一题一轮四次调用。** 问题是打勾时带的那句话，默认「主播的论点站不站得住」，也是一个问题。一轮 = 列假设（模型）→ 核实（0013：代码检索、模型判）→ 推理（模型）→ 反方（模型）。代码做：命题排队、说法匹配、台账写入、矩阵合并与快照、非诊断行归档、缺口转核实队列、指标到期、页面重画。同一条述线几题一起跑时，列假设一题一次，核实队列按命题合并去重，推理与反方各题一份。五道工序里正字已归每晚处理（0010），串联走关联述线的评估摘要与回顾整体，读意只留字段，真正按题跑的是核实与推理。
2. **列假设在核实之前，决定核什么。** 输入：问题、述线名与说明、全部述段的头、说法一行头（含 type / stance / 转述自）、上轮摘要、关联述线各问题的评估一行；不给整理稿正文、不给原话。输出四张表。**假设表**：id 跨轮稳定、一句可检验的文本、持有者（主播 / 嘉宾 / 外部某方 / 对立，核实后代码按来源换成有名字的）、类型（现状判断 / 预测 / 解释）、预测类的到期、对立于哪条；复合论点拆开（一半现在能核、一半要等的拆成两条）；每条主播假设至少配一条对立假设；封顶 8 条。**命题表**：每条说法拆成自足命题，挂关联假设与方向（撑 / 反 / 两可，可多条）、诊断力（高 / 中 / 低 / 无）、可核（评价与推测标否、留作主播立场）、当事地区与当地语言检索词。**派生待核事实**：从论点、评价、预测里按主播的方向派生成可判对错的命题，标派生自哪段。**先例候选**：哪件事、对哪条假设、为什么像，用到的事实各写成命题进核实队列（诊断力最高给中，排在直接证据后）。大述线首轮按播出日分窗：第一窗建假设表，后面各窗带着假设表只分派新命题。
3. **推理不联网、不吃正文，只用台账里的材料。** 输入：问题与假设表；命题行（代码从台账拼：文本、判定、把握、现在、关键来源一两条带立场一句与引文片段、谁说的、EP@ts、播出日；未核的标「主播立场」或「待核」）；述段头加每段原话；上轮评估摘要、诊断行摘要、反方、开着的缺口与指标、本轮新增与改判标记；关联述线评估一行。输出：矩阵、评估、论证链、问题的答案与变了什么、事件脉络、主播前后矛盾、对判定的质疑、缺口、指标。**矩阵**行是证据（核过的命题、先例、自相矛盾的一对说法），列是假设，格是撑 / 反 / 两可 / 无关加一句注；证据的分量不由模型定，代码从台账带判定、把握、来源立场标签、独立来源数；全行两可或无关的是非诊断行，代码归档不进页面。事件脉络的日期来自核实层记下的证据，缺日期的事列成缺口。
4. **缺口闭环。** 推理要台账里没有的材料，写成缺口：待核事实 / 要的数据 / 想听主播讲 / 等时间。待核事实类直接写成命题加检索词，当场排进核实队列，同一次运行里最多再转一圈（面板旋钮），补进台账后再推理；转完还缺的留在缺口，这轮把握封顶「中」，页面写「缺 N 项」。「想听主播讲」类由每晚新段挂上时代码去撞，撞上在初筛页出一行。
5. **估计用语：可能性五档，把握三档，分开写。** 可能性 很不可能 / 不太可能 / 五五开 / 可能 / 很可能，内部存区间（≤20 / 20–45 / 45–55 / 55–80 / ≥80），页面只显示词。把握 高 / 中 / 低 加原因（来源少 / 单一立场 / 口径不一 / 反方未跑 / 关键证据待核）。词只从枚举里选，schema 卡；自由文本里不许再用「可能」「大概」描述可能性。档位主要按反证的行数与分量定，撑的多不算数；只有社媒视频或单一来源撑的行不抬可能性；同一立场的来源撑起来的假设把握降一档。每条评估必列压在哪几行、关键假定、持有者 vs 主流一句、变了什么（首轮 / 因哪条证据或改判升降 / 不变）。评估行标「AI 估计」，永不进「我的判断」。
6. **论证链，每条主播假设一条。** 论据（命题 id 加判定）、推论（主播从论据到论点的那一步）、薄弱处四选一：论据不实 / 推不出 / 漏了变量 / 无，加一句。它回答的是「断在哪一环」，不只是有几条事实错了。
7. **反方独立调用，默认开，用另一个模型。** 输入推理产出加命题行，不给正文。输出每条被看好的假设：被攻的假定与怎么破、薄弱行与为何薄、替代解释（进下一轮假设候选）、推翻条件（转指标候选）、依据薄弱的判定（转台账「复核」）、总评。反方不改评估，单独记一块，下一轮推理把它当输入。再跑时「变了什么」为空就不跑；面板可关；关了或没跑的那轮把握封顶「中」。
8. **先例是证据的一类，主流是矩阵的列，说法怎么变由代码派生。** 先例不单独成节：列假设提、核实查它的事实、推理在矩阵里打向并写同在哪、不同在哪两句，页面标「先例」。另加「参考类别」：这类事历史上多少次成了、多少次被吸收，写成派生命题去核，把握一般低。外部看法成为对立假设的持有者，证据对它和对主播的假设一起打向；评估里「主播差在哪」是他的假设与持有者最多、把握最高的那条之间的差，「什么事能分高下」是指标。价值判断不进矩阵，只在来源表记立场。「说法怎么变」的骨架由代码从台账按假设、按播出日列出；推理只加「自相矛盾」行。
9. **问题的账：每轮一份记录，只追加。** 记录含问题 id、轮次、运行 id、用的述段与命题（含判定版本）、假设表快照、矩阵差分与代码合成的完整快照、论证链、评估、答案、事件脉络、矛盾、质疑、缺口、指标、反方、按调用分列的 provenance。述线页「现状」每题一行和深加工页整版都是它的派生视图。同题再跑不整份带：带假设表与上轮评估一行、诊断行摘要、本轮新增与改判的命题全行、上轮反方、开着的缺口与指标；模型只输出差分，代码合成快照；超预算的大述线旧行按假设分组只带分量最大的前 N 行，其余给计数。新假设出现时归档的行按一行摘要重过一遍。
10. **页面按读的三个时刻排节，判断放最前。** 几秒：初筛页与述线页每题一行（最可能的假设、可能性、把握、变没变）加预警行（指标到期、新段撞上缺口、新说法与已核事实相抵）。三分钟，深加工页顶部五块按序：判断 → 论证链 → 关键假定 → 变了什么 → 缺口与指标。要钻，页面下部七块默认折叠：矩阵按假设列撑与反（先例行单标、每行带来源立场）→ 主流 vs 主播 → 反方 → 记分（他在这题上说对的与落空的，说话人三项限定到本线）→ 事件脉络 → 台账视图 → 信源。删掉或并掉：现状散文、说法怎么变散文、「有见地的分析」独立一节、述线级整体徽标。六问的材料一样不丢：讲了什么归时间线与整理稿，重大事实偏差归台账视图，支持与不支持归矩阵，先例归矩阵先例行，有见地的分析归对立假设列与来源立场，信源归来源表。
11. **读意只留字段，不跑。** 来源记录加正文缓存 id；说话人表加立场一句、常引的上游。不加别的，不进页面。
12. **模型与预算。** 列假设 sonnet/high 约 2 万峰值（拿 DSA 对照一次 opus 再定）；核实一批 ≤ 6 万（0013）；推理 opus/high 约 4 到 5 万，一到两轮；反方 sonnet/high 约 2 万。都在 12 万内，不随历史涨。今天与各集播出日由 runner 下发，prompt 不含日期。深加工排队不设自动排法，先勾先做加面板手动拖。
13. **不做的。** 不出概率；不打信用分；读意不跑；串联不另开调用；#92 的贝叶斯更新不碰，只保证记录形状不堵它。

## Rationale

**为什么问题驱动。** 六问是好分析的全部材料，缺的是脊柱：判断是什么、凭什么、什么事会让它变。给材料装脊柱的办法是先问一个问题，再列能回答它的假设，证据只对假设打向。情报分析的标准做法（Heuer 的竞争假设分析）就是这个顺序：列假设、列证据、做矩阵、归档非诊断行、按反证评估、做敏感性、估计全部假设、定指标；四次调用与代码各管其中几步。

**为什么列假设在核实之前。** 核什么由诊断力定（0013），而诊断力只能相对假设定义。原型最能分辨论点的 8 句话不在核查清单里，就是因为核查在前、没人问「核这条能分辨什么」。列假设便宜（约 2 万 token），把它放在前面，核实花的钱才花在能分辨论点的命题上。

**为什么推理不联网、不吃正文。** 用户的理由：推理用的材料必须都进台账，否则事后判不了推理质量；推理要别的材料就和缺日期一样写成缺口，补进台账后再推理。这同时解决了三件事：搜索记错与成本一半在搜索（检索挪到核实层的代码里）、输入随正文涨（原型只挂两集已 6.5 万，大述线装不下）、评估不可追溯（每行证据有 id、有判定版本）。不吃正文是因为核实那层已经把语境精简过一轮，论证骨架在述段头、原话与评价类命题里；原型 32 条核查没有一条因语境少判错。

**为什么矩阵取代两列。** 支持 / 不支持两列只能对一个没定义的「主线」说话；22 条里只有 14 条真是证据行，其余是复述判定、离题和没地方放的变量。按假设打向，谁对谁错才看得见，离题的格子全是无关、自动归档，「主播事实错」与「证据反论点」分开。

**为什么五档不七档。** ICD 203 的七档去掉两头。模型分不清 5 到 20 与 20 到 45，没有校准数据前七档是假精度；读者的动作在相邻两档之间不变，五档已够表达偏向哪边、偏多少；两头的「几乎不可能」「几乎确定」要决定性证据，我们的证据多是报道，给不出；「说不准是证据少还是证据相抵」已经由把握三档分开，可能性不用再细。内部存区间，以后预测台账攒够兑现数据可改回七档或出数，只是换标签。词与自由文本分开是 ICD 203 不许混用的规矩。

**为什么论证链。** 用户的要求是「论据多假则论点可疑」。只报错了几条事实，读者不知道该怎么想；写成论据、推论、论点三段并标断在哪一环，断的是事实、是推理、还是漏了变量，三种断法读者的反应不一样。这是 Toulmin 论证模型最简的用法。

**为什么反方独立、默认开、用另一个模型。** 同一个模型自己反驳自己容易顺着说；换模型才是第二双眼。反方便宜（约 2 万），而没经过唱反调的估计不配「高」把握，所以默认开、关了封顶。反方攻的是关键假定，所以评估里假定与判断分开写。

**为什么先例进矩阵、事实要核、加参考类别。** 先例是外部视角，是六问里最好的一条，但原型的先例数字没核，「模型自带知识不作依据」在这一层没守；写成派生命题进核实队列才守得住。一个先例是一个故事，参考类别是基率：这类事历史上多少次成了、多少次被吸收，比故事更能校正判断。

**为什么记分。** 原型只列偏差，读者看到的全是主播错的地方，既不公平也校不准信任；把说对的和落空的一起列、限定在这条线上，读者才知道该信他几分。

**为什么按三个读的时刻排。** 阅读负担是红线：人每天只有几分钟。ICD 203 要求关键判断放最前；Tetlock 的要求是分析要能被结果判，所以缺口与指标带到期、预测进预测台账。三层让同一个页面既能三秒扫、也能三分钟读、也能钻到每一行证据。
