# 0003. 日报取代断言表：取消每日人工闸门，「判真假」受约束回归

**Date:** 2026-09-12（决定形成于 2026-09-10 至 09-11）
**Status:** Accepted

## Context

2026-07-27 的 SPEC v2 把项目定为**断言表**：一集直播抽成几十条带行内字段的 list item，人每天在 `_review/` 里审一遍（阶段 3，「唯一花时间的地方」），审过的行落进 EP 笔记，跨集比对靠 Dataview 查询，综合归人。同一份 SPEC 把难度分成三层——①听清、②理清、③判真假——并**明确删掉第③层**，理由是判真假没有底、而且会替人下结论。

到 2026-08 这条线跑通了阶段 0（ADR 0002）和 `channel` 抽取（`scripts/stage12.py`，EP03 抽出 8 条）。用户看到产物后的评价是：「之前的效果我记得是差不多每个视频抽出 8 个判断，我觉得这是很糟糕的形式」。他要的东西是另一组问题：昨天讲了什么（不要简略）、有没有重大事实偏差、支持和不支持的证据、历史上有没有类似情况、当时和现在的环境差在哪、有没有特别有见地的分析。

2026-09-10 用户提出第三次定位：**把关注的多个 UP 主的直播录播和视频，自动做成一份日报**，长度不限；AI 做信息初筛与整理，知识与事实的构建归人，而且人只在**周末**做这件事。2026-09-11 用 EP02 真实逐字稿做了三种版式的原型（`docs/prototypes/daily-digest/`），用户选定「按事件读」，评价「比预想的好、更实用」。

## Decision

1. **产物是日报**，一天一篇 markdown，不是断言表。单集整理稿是日报的输入，**全长、不压缩成条目**，每段带回到原话的时间戳。
2. **按事件读**：事件索引 → 每个事件一张六问卡（讲了什么 / 重大事实偏差 / 支持的证据 / 不支持的情况 / 历史先例与当时 vs 现在 / 有见地的分析）→ 其余话题只整理不核查 → 跨 UP 对照 → 他们提到的信源。
3. **每日人工审核闸门取消。** 人每天只读日报；周末确认核查判定、写自己的笔记。质量责任移到代码里的机械闸门和高思考深度的核查层（ADR 0004）。
4. **「判真假」回归，但受四条约束**：只核可核查的说法（数字、时间、归属、引述），主播自标「应该」「大概率」的推测不核；判定是 AI 初判（ok / warn / bad / none），**每条必带来源链接，没有链接不得判「讲错」**；核查层只加批注，**不得改写整理层的文字**；每个事件、每条可核查的说法都核，不设上限（用户 2026-09-12 拍板「内容有多少处理多少」）。
5. 目的 (B)「学会主播的信息源」降为日报的固定一节「他们提到的信源」，不再是抽取的一等对象。
6. 断言表的数据模型——`type` 五类、`情态` 轴、主题词表、`entities.json`、Dataview 总库查询——整体退役。

## Rationale

**为什么断言表输了。** 它把一场三小时的直播压成几十条碎片，赌的是「人会在碎片上做综合」。但用户实际能投入的是周末读一遍，不是每天审几十条；碎片丢掉了「讲了什么」的连续性，而连续性正是他要的东西。原型的整理稿 12,006 字、24 到 30 分钟读完，对应 191 分钟收听——这个比例成立，断言表那条路上从来没有成立过。

**为什么敢取消每日闸门。** 闸门当初挡的是抽取脑补和 ASR 错误。原型证明这两件事有更便宜的防线：引文逐字命中逐字稿段落的代码闸门（零额度、确定），加上联网核查层——它在 EP02 上抓到了真错：川普支持率「福特以来最高」说反；盖洛普 52%/12% 实为 89%/3%；印度穆斯林人口全球第三而非第四；台积电亚利桑那「几百块芯片」已过时；「缺电游行 20 万人」张冠李戴；「2026 年 8.76%」实为 2025 年；休达「6 万人」为真而主播自标「以讹传讹」。这些都不是每天人工审几十条能审出来的。

**为什么第③层能回来。** 2026-07 删它的两个理由——没有底、替人下结论——各有一条约束对应：只核可核查的说法（数字、时间、归属、引述），主播自标的推测不核，「底」由此划定；判定只是带链接的初判，人 30 秒就能复核，终审仍归人。约束比禁令便宜。

**已知风险。** 「有见地的分析」是六问里最难验证的一问，只能靠附链接和标明立场兜底；限定词保留还没有机械闸门（只能尽力检查）；跨 UP 的事件聚类成了承重步骤，聚错一个事件，整张对照表就错。

## Consequences

- `SPEC.md` 全量重写为 v3；`CONTEXT.md`、`CLAUDE.md` 同步。v2 走「备份 commit → 删备份 commit」两步，可按文件名 `SPEC.BACKUP.md` 从备份 commit 取回。
- 红线改写：「人工审核只审提取产物」变成「人每天不看任何中间产物，日报阅读时间必须远低于收听时间」；「综合归人」保留（事件笔记里人写的区块软件永不覆盖）；新增「核查必带链接」「核查不改整理」。
- vault 结构变：`10-Episodes/` 存整理稿，新增 `20-Daily/`（日报）与 `30-Events/`（跨天事件笔记）；`15-Materials/`、`_review/`、`_queries/`、`_index/` 退役。
- 旧票 #1 到 #49 于 2026-09-12 全部关闭，#50 跟踪 v1。`docs/research/`、`docs/vision.md`、`docs/prototypes/issue-7/`、`.sandcastle/` 移出仓库。
- **保留的**：阶段 0 全部代码与队列状态机（ADR 0002）、时间戳跳播插件（ADR 0001）、`stage12.py` 的分块 / 无头调用 / 闸门 / 原始响应留档。
- 仓库是公开的：含逐字稿片段的整理稿、页面数据、拼好的 HTML 一律不入库，留在 vault 的 `_lab/`。
