# issue #52 · L2 逐章节整理

## 为什么做

笔记里那块现在只有十来行章节大纲，想知道他**怎么**讲的还得回去听三小时录播。
整理稿是人每天唯一会读的东西——不做它，切章白切、核查没素材。

## 改了什么

整理的单位定在一章：模型在章内切话题、分正题 / 旁白 / 过场、写五类内容，
只用行号指位置，时刻与编号由代码填。笔记那块从大纲变成逐话题的整理稿。

## 效果

`_digest/` 多出每话题一份片段与一张话题表；EP 笔记一个话题一节（段落、锚点、
说法、信源表、生音），`整理版本` 变 `L2-topic@0.1`。一集多十来次调用。

## 最大风险

正题被判成 `filler` 会整段从笔记消失——盯块首行「另有 N 段杂项未渲染（合计 …）」，
超 15 分钟就去 `_digest/` 翻那几个片段。并发 3 在真机上是头一回：某章挂了应当进
`_failed/`、整集 `整理: failed`、退出码 1；评审修掉一处会让这个信号消失的缺陷
（旧话题表替失败的章顶包，笔记留一串空标题却写 done）。头一次用 `--workers 1` 跑。
