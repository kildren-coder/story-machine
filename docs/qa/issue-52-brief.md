# issue #52 第二轮 · L2 字数预算进输入

## 为什么做

EP02 实跑第一轮压缩比 0.73，读完 100 分钟，几乎白省。prompt 从没提过长度——不治，
L2 交的就是换了排版的逐字稿。

## 改了什么

代码按汉字数算出本章目标字数（逐字稿 × 0.2）下发给模型；prompt 教它省「怎么说
的」不省「讲了什么」，四种靠删内容凑短的写法禁掉。不设闸门——代码判不了短是写得
好还是删了事。

## 效果

输入的头六行变八行；日志每章报正文对目标、整集报压缩比。产物与调用次数不变，
prompt 升版只报不重跑。

## 最大风险

靠删内容达标：整段事从笔记上消失，测试与日志照样绿。合并后对冻结的 EP02 基线逐章
比 title、kind。

压根压不下来：预算只是软目标，prompt 里「全长」那句还在。看末行压缩比，0.5 上下
就是没起作用。
