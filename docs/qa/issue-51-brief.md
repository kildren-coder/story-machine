# issue #51 · 骨架（曳光弹）：Extract EP → L1 话题表 → EP 笔记出现可跳播大纲

## 为什么做

阶段 0 跑完就断档：逐字稿躺在 `_assets/` 里，人还得自己从头听。旧的 stage12 只往
`_review/` 堆待审草稿，跟「人永不审中间产物」的红线反着来。

## 改了什么

打穿一次「逐字稿 → 模型 → 产物 → 笔记」全路径：机械件拆成各层共用的包，接上第一层
（整集切话题），旧的分块-审稿脚本退休。

## 效果

`-Extract EP02` 后 `_digest/` 多一份带 provenance 的话题表、`_pairs/` 多一对输入与
原始响应，EP 笔记长出能点时间戳跳播的大纲，frontmatter 记 `整理: done`；产物在就
跳过，`-Redo` 才重跑。

## 最大风险

**覆盖检查全有或全无**：模型在 3 小时里任何位置留 >5 秒的缝，整集进 `_failed/`、笔记
打 `整理: failed`，没有部分产物。第一时间看退出码 1 与 `_failed/EP02/L1-all.failed.json`
里带时间戳的错误行；栽了改 prompt 升版本，别放宽阈值。

**写回是在人的笔记上原地手术**：块外被动了就是人写的段落没了。第一次跑完先用
Obsidian 版本历史确认只多了那一块加两行 frontmatter。
