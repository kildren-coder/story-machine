# issue #80 阶段 0 转写 · 吞块补解

## 为什么做

batched 管线把语音拼成 ≤30 秒的块，每块只解一遍、没有降温重试，长块会被整块吞掉。
EP02 正本因此少了约 3450 个汉字，占全文 6%——这种缺字下游花多少钱都找不回来。

## 改了什么

第一遍收完段之后、写盘之前，把「字太少或块内空着一大段」的块挑出来，只改切块长度
（15→10→7 秒）拿同一个模型重听，取汉字最多、又确实保住原文的那一版换回去；不用
LLM，不碰别的块。判据与阶梯是一层纯标准库的规则，能离线演示。

## 效果

worker 日志多一行 `redecode: suspects=… replaced=… residual=…`，正本顶层多一个
`redecode` 块（规则参数 + 逐块明细），`config` 末尾多 ` redecode`。全集汉字只增不减。

## 最大风险

复算的 VAD 块对不上第一遍的段：整步跳过，正本与旧流程逐字节相同，功能等于没上。
日志头一行 `chunks=N segments=M` 两数不等就是它，当场看得见。

7 秒那一级在真实音频上没跑过，补回来的可能是通顺的幻觉（复读判据拦不住）。转写后
在正本里过滤 `picked == 7` 的块，按 `start`/`end` 抽听。
