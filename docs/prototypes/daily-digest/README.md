# 原型：多 UP 主日报（2026-09-11）

**问题**：新定位下「日报」长什么样，才是用户想要的效果？（三种版式可切换，`?variant=A|B|C`）

**素材**：EP02《瓜熟迪落拉》2026-08-02 直播录播（3h10m，瓜哥 × 历史哥），真实逐字稿。

**结论**：用户选 **B「按事件读」**（事件索引 → 每事件六问卡 → 其余话题只整理 → 跨 UP 对照 → 信源），评价「比预想的好、更实用」。A/C 弃用；C 的旁注形式可作为六问卡内的次级样式备选。定稿结构见 SPEC §5.7，执行形状见 ADR 0004。

**发布**：https://claude.ai/code/artifact/692b935d-3031-4f99-8d43-e6e70995dc60

## 仓库里留什么

`check-A/B/C.json`：三件事的联网核查结果（sonnet 子代理产出，每条判定带 URL），是 L5a / L5b 的质量参照与候选 golden：

| 文件 | 事件 | 主时间戳 |
|---|---|---|
| `check-A.json` | 2026 年中期选举：川普的三个动作 | EP02@01:04:32 |
| `check-B.json` | DSA 谱系：从桑德斯到马姆达尼 | EP02@01:17:56 |
| `check-C.json` | 台湾「芯片共和国」：台积电亚利桑那、缺电游行、高增长与高民怨 | EP02@02:39:19 |

字段与 SPEC §5.6 有出入（`links` 是 `{t, url}` 对象而非字符串；`support[].text` 对应 §5.6 的 `point`；`event` 只是字母），以 SPEC 为准。

含逐字稿片段的东西不进公开仓库（红线 10）：整理稿草稿、话题片段 JSON、页面数据、模板、拼装脚本与拼好的 HTML 都在 vault `_lab/daily-digest-proto/`。
