# 美国国会八人帮

## 概述

美国国会中负责接收行政部门最高密级情报通报的八个法定职位的非正式统称。据本集主播介绍，它「不是某几个人，而是对某八个职位的一个概括」，由国会情报委员会与两院领导层构成，可接收原本汇报给总统的最高机密情报。该机制由小布什在 911 之后设立，用作政治与军事指挥的「备份」。
