## 按流程顺序看

1. `_review/EP01-c02.draft.md` — **审核草稿**。阶段2 由 CC 无头产出，每条带 `source_quote` + 三闸门自检；`⛔` 是 #47 对抗初筛替你挑出的可疑条目（本例：把主播「应该是」的推测固化成了事实断言）。**你唯一要亲自看的界面。**
2. `25-Organizations/美国国会八人帮.md` — 草稿审完后的**成品笔记**（给人读）。frontmatter 扁平字段 + 正文纯 prose + `[[双链]]` + 固定锚点，正文**零** `key:: value`（#39 约定A）。
3. `25-Organizations/美国国会八人帮.json` — **JSON 边车**（给机器读）。别名带 `语域`、`provenance` 带钥匙+`source_quote`、关系带受控大类+原文（#39 + #3）。
4. `_index/sources.json` — **信源补全索引**（你最关心的「找出报道真身/链接」）。S-0001/S-0002 是真实的补全失败例，S-0117 是金融时报「已补全」示范。
5. `10-Episodes/EP01 外国如何干涉美国选举.md` — **单集 MOC**，只做导航双链，不重抄实体（#3 议题1）。
6. `_pairs/EP01/chunk02_pre.md` — **校对配对快照**。`engine: claude-opus-4-8` 让「草稿来自谁」机械可判定；全程走 CC 后训练用途默认关闭（#14）。
